# Akashmika Behera: Portfolio

Personal portfolio of Akashmika Behera, Product Manager for data, analytics and regulatory products in banking and insurance.

Live site: https://akashmika.github.io

## Contents

| File         | Purpose                                             |
| ------------ | --------------------------------------------------- |
| `index.html` | All page content (single page)                      |
| `styles.css` | Layout, typography, colours and responsive rules    |
| `script.js`  | Mobile menu toggle and current-section nav highlight |

Plain HTML, CSS and vanilla JavaScript. No framework, build step or dependencies. Fonts load from Google Fonts, with system fallbacks.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Publish with GitHub Pages

This repository is named `akashmika.github.io`, so GitHub serves it as the user site at https://akashmika.github.io.

1. Push to the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`.

## Updating content

All text lives in `index.html`. To change the accent colour, edit `--accent` at the top of `styles.css`.
